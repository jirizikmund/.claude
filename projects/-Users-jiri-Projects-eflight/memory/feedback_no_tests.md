**Why:** Uživatel explicitně odmítl bod "chybějící tests" z code review (#2535). Projekt má jinou testovací strategii (manuální / vizuální kontrola).

**How to apply:** Netrvat na testech v návrzích implementace ani code review. Nepřidávat test suite pro nové funkce. Nezmiňovat absenci testů jako defekt.
