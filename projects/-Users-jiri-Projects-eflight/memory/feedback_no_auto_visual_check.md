name: Nespouštět automatickou vizuální kontrolu
description: Nepoužívat eflight-visual-inspector automaticky po změnách, uživatel provádí kontrolu ručně
type: feedback
---

Nespouštět eflight-visual-inspector agenta automaticky po každé změně kódu.

**Why:** Uživatel preferuje provádět vizuální kontrolu ručně v prohlížeči, automatická inspekce je pomalá a zbytečná.

**How to apply:** Vizuální inspekci spouštět pouze když o ni uživatel explicitně požádá. Po změnách UI stačí TS check.
