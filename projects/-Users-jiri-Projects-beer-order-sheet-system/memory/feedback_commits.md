Commitovat po logických celcích. Každý commit = ucelená funkční jednotka.

**Why:** Uživatel chce přehlednou git historii a možnost kdykoli navázat na rozpracovanou práci.

**How to apply:** Po dokončení každé logické části (např. analýza, setup projektu, auth modul) udělat samostatný commit. Vždy uložit vše potřebné do memory, aby bylo možné navázat v nové konverzaci.
