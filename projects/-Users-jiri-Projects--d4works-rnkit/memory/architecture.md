# rnkit Architektura

## rnkit.config.json

Konfigurační soubor v kořeni **cílového projektu**. Čte se build-time skripty, nikdy za běhu.

### Sekce
- `constants` — appStoreId, googlePlayId, appWebUrl
- `api` — inputSwaggerFile, outputApiFolder
- `i18n` — outputI18nFolder, inputSrcFolder, locales, localesFallback, notTranslatedValue, localeSourceForTranslation
- `fonts` — files (font soubory), definitions (DEFAULT, INPUT_TEXT, INPUT_LABEL, INPUT_ERROR, BUTTON_TITLE, BUTTON_SUBTITLE)
- `colors` — klíč-hodnota mapa custom barev
- `sentry` — dsn

### Čtení configu
- `src/scripts/rnkitConfig.ts` — `readRnkitConfig()`, `readRnkitConfigAll()`, `writeRnkitConfig()`
- Helpery pro jednotlivé sekce: `getConstantsConfigOrCreateNew()`, `getFontsConfigOrCreateNew()`, `getColorsConfig()`, `getSentryConfig()` atd.
- Interaktivní prompt pro chybějící hodnoty (constants, fonts, i18n) — sentry nemá prompt, jen tiše vrátí undefined

## Build-time generování souborů

Pattern: config → build-time skript → generovaný .js/.d.ts soubor → import za běhu

| Sekce | Skript | Generované soubory |
|-------|--------|--------------------|
| fonts | `src/scripts/fonts/` | `src/stylekit/fonts.js` + `.d.ts` |
| colors | `src/scripts/colors/` | `src/stylekit/colorsCustom.js` + `.d.ts` |
| constants | `src/scripts/constants/` | regex replace v `src/utils/env/index.ts` |
| sentry | `src/scripts/sentry/` | `src/utils/sentry/sentryConfig.js` + `.d.ts` |

Generované soubory mají header: `This file was generated by RN toolkit, do not edit it manually.`
Jsou trackované v gitu (ne v .gitignore).

## ToolEnv

Skripty běží ve třech režimech (`ToolEnv`):
- `dev` — vývoj rnkitu samotného
- `project_root` — spuštěno z kořene cílového projektu
- `project_lib` — spuštěno z `node_modules/@d4works/rnkit`

Cesty k souborům se liší podle režimu (js folder, ts folder).

## Postinstall

`src/scripts/postinstall/index.ts` — spustí se automaticky při instalaci rnkitu:
1. i18n postinstall
2. Splash
3. Fonts
4. Colors
5. Constants
6. Sentry

Stejné pořadí v `tool.ts` case `postinstall`.

## CLI tool

`src/scripts/tool.ts` — hlavní entry point pro `yarn rnkit` příkaz.
Dostupné nástroje: postinstall, build, run, api, i18n, translate, fonts, colors, splash, constants, sentry, svg

## Exporty

- `src/index.tsx` — hlavní barrel, exportuje `* from './utils'`, `* from './components'`, `* from './i18n'`, plus named exporty
- `src/utils/index.ts` — utils barrel, exportuje SentryService a typy
- Cílový projekt importuje z `@d4works/rnkit`

## APP_ENV

- Typ: `'test' | 'production'`
- Definováno v: `src/utils/env/appEnv.ts`
- Zdroj: `Constants.expoConfig.extra.appEnv` z `app.json`
- Synchronně dostupný (není async), fallback: `'test'`
- Použití: `STATIC_ENV.APP_ENV`, `ENV('APP_ENV')`, `AppEnvSelect()`

## Sentry

- `src/utils/sentry/index.ts` — `SentryService` (statická třída)
  - `init()` — bez parametrů, DSN z `sentryConfig.js`, environment z `APP_ENV`
  - `captureException()`, `captureMessage()`, `addBreadcrumb()`, `addXHRRequestBreadcrumb()`
  - Všechny metody no-op když `isInitialized === false`
  - `isInitialized` flag — true pouze po úspěšném `init()` s platným DSN
- `src/app/init.ts` — `SentryService.init()` se volá synchronně **před** `Promise.all` v `initRnkit()`
- `src/app/RnkitAppProvider.tsx` — podmíněný `Sentry.TouchEventBoundary` wrapper (Fragment pokud Sentry off)
- API šablony (`lib_source/api/`):
  - `__IMPLEMENT_HELPERS__.ts` — `captureSentryMessage()` volá `SentryService.captureMessage()`
  - `__IMPLEMENT_API__.ts` — `xhrSentryLogMiddleware` volá `SentryService.addXHRRequestBreadcrumb()`
- `@sentry/react-native` je hard dependency (všechny cílové projekty Sentry používají)
- Nový build Expo aplikace je **nutný** po přidání Sentry (obsahuje nativní kód)

## Lib šablony (lib_source/)

- `lib_source/api/` — šablony kopírované do cílového projektu při generování API
- `__IMPLEMENT_*.ts` soubory jsou editovatelné uživatelem (ne generované)
- Importují z `@d4works/rnkit` (ne relativní cesta do rnkitu)
- `utils/` soubory (BaseApi, helpers, types) mají header "generated by RN toolkit"

## Build procesu rnkitu

- `tools/build.ts` — interaktivní (Build / Build+Sync+Reinstall)
- Používá `react-native-builder-bob` (`yarn bob build`)
- Výstup do `lib/` složky
- `lib/` je v .gitignore
- Po buildu: minifikace uglifyjs, vytvoření package.json, kopie lib_source
